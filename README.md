# pessoal-med-web

**PrescMed** — calculadora de dose pediátrica/adulto, hidratação (Holliday-Segar e Protocolo Dengue), solicitação de exames e atestado médico (conforme CFM).

Repositório pessoal, em construção.

## Como usar

Aplicação 100% estática (HTML/CSS/JS puro, sem build e sem backend). Basta abrir o `index.html` no navegador, ou servir a pasta com qualquer servidor estático.

## Aviso

Ferramenta de apoio à decisão clínica para uso pessoal. Os cálculos e valores de referência não substituem o julgamento clínico do profissional responsável — sempre confira doses e protocolos antes de prescrever.
